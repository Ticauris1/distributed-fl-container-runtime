# Archived segmentation experiments

These runners produced exploratory studies that are no longer part of the
active paper-facing workflow. They are retained for reproducibility and can be
restored if an earlier ablation needs to be regenerated.

The active workflows are:

- `segmentation_centralized`: three-seed, 384-pixel encoder comparison.
- `segmentation_federated`: sample-size versus paper-CELM under IID and
  crack-area skew with two or three clients.
